# monsmain

درگاه یکپارچهٔ مدل‌های هوش مصنوعی همراه با پنل مدیریت. نسخهٔ ۱٫۰٫۰.

این برنامه یک نقطهٔ اتصال سازگار با رابط OpenAI می‌سازد تا همهٔ ابزارهای شما (ادیتور، کلاینت چت، اسکریپت‌ها) بتوانند به‌صورت یکپارچه با مدل‌های رایگان و اشتراکی کار کنند.

## ارائه‌دهنده‌ها

در این نسخه دقیقاً دو ارائه‌دهنده پشتیبانی می‌شود:

| ارائه‌دهنده | احراز هویت | توضیح |
| --- | --- | --- |
| OpenCode Free | بدون کلید | مدل‌های رایگان، آمادهٔ استفاده |
| NVIDIA NIM | کلید API | کلید را از build.nvidia.com بگیرید |

مدل‌های رایگان OpenCode با پیشوند `oc/` و مدل‌های انویدیا با پیشوند `nvidia/` فراخوانی می‌شوند.

## پروفایل چندگانه و گردش نوبتی

برای OpenCode می‌توانید چند **پروفایل** بسازید. هر پروفایل یک هویت مستقل است: نام، پروکسی خروجی و سهمیهٔ مصرف جدا.

مسیر ساخت: پنل ← Providers ← OpenCode Free ← دکمهٔ «Add Profile». کلید گردش نوبتی و تعداد درخواست هر پروفایل پیش از جابه‌جایی، در همان کارت قابل تنظیم است.

## راه‌اندازی

```bash
npm install
npm run build
npm start
```

پنل روی `http://localhost:20128` بالا می‌آید. برای تغییر درگاه:

```bash
PORT=8080 npm start
```

### متغیرهای محیطی

| متغیر | کاربرد |
| --- | --- |
| `INITIAL_PASSWORD` | گذرواژهٔ نخستین ورود به پنل |
| `JWT_SECRET` | کلید امضای نشست‌ها؛ مقدار ثابت و تصادفی بگذارید |
| `DATA_DIR` | محل نگهداری پایگاه داده و پشتیبان‌ها |
| `PORT` | درگاه پنل، پیش‌فرض ۲۰۱۲۸ |

نمونهٔ کامل در فایل `.env.example` آمده است.

## پایگاه داده

همه‌چیز در یک فایل SQLite نگهداری می‌شود. در ویندوز مسیر پیش‌فرض `%APPDATA%\monsmain\db\data.sqlite` و در لینوکس و مک `~/.monsmain/db/data.sqlite` است. برای انتقال یا پشتیبان‌گیری همین پوشه را کپی کنید؛ از داخل پنل هم بخش پشتیبان‌گیری در دسترس است.

## نشانی‌های سازگار با OpenAI

| نشانی | کاربرد |
| --- | --- |
| `POST /v1/chat/completions` | گفتگو |
| `GET /v1/models` | فهرست مدل‌ها |
| `POST /v1/messages` | ورودی سازگار با Anthropic |
| `POST /v1/embeddings` | بردارسازی متن |
| `POST /v1/audio/speech` | تبدیل متن به گفتار |

نمونهٔ فراخوانی:

```bash
curl http://localhost:20128/v1/chat/completions \
  -H "Authorization: Bearer YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"oc/beam-free","messages":[{"role":"user","content":"سلام"}]}'
```

کلید را از بخش «Endpoint & Key» در پنل بسازید.

## بخش‌های پنل

- **Endpoint & Key** — آدرس درگاه، ساخت و مدیریت کلیدها، تنظیم ابزارهای بیرونی
- **Providers** — اتصال‌ها و پروفیل‌ها، آزمون تک‌تک، پروکسی هر اتصال
- **Combos** — زنجیرهٔ جانشین: اگر مدل نخست پاسخ نداد، مدل بعدی امتحان شود
- **Usage** — مصرف روزانه و تفکیک مدل و ارائه‌دهنده
- **Token Saver** — کاهش مصرف ورودی با فشرده‌سازی محتوا
- **Proxy Pools** — استخر پروکسی و گردش بین آن‌ها
- **Console Log** — رهگیری زندهٔ درخواست‌ها
- **Settings** — گذرواژه، تم، رفتار پیش‌فرض

## نکته‌های عملیاتی

- پنل تک‌کاربره است و با گذرواژه محافظت می‌شود؛ نشست‌ها با `JWT_SECRET` امضا می‌شوند، پس این مقدار را تغییر ندهید.
- اگر پشت پروکسی معکوس اجرا می‌کنید، `BASE_URL` را روی نشانی عمومی تنظیم کنید.
- فایل پایگاه داده را هنگام اجرا کپی نکنید؛ برای پشتیبان‌گیری از دکمهٔ پشتیبان در پنل استفاده کنید.
